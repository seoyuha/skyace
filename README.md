# SKY ACE 영어 복습 출격

6학년 영어 1~12단원 복습 슈팅 게임. 반별 순위와 교사 관제실이 들어 있어요.

- 학생 주소: `https://(내 주소)/`
- 교사 관제실: `https://(내 주소)/teacher.html`
- 교사 비밀번호: Render의 환경 변수 `TEACHER_PASSWORD` (설정하지 않으면 `finel9932!`)

## 두 가지로 쓸 수 있어요
1. **혼자 연습용** — `public/index.html` 파일 하나만 GitHub Pages·Netlify에 올리면 돼요. 기록은 저장되지 않아요.
2. **반 기록용(Render)** — 이 폴더 전체를 GitHub 저장소에 올리고 Render에 연결해요. 학생이 반을 고르고 별명을 쓰면 기록이 저장되고, 반 순위와 교사 관제실이 켜져요.

## 수업 진행
1. 교사 관제실 → **오늘 출격 설정**에서 반마다 복습할 단원(여러 개 가능)과 난이도를 고르고 저장해요.
2. 학생은 반을 고르고 별명을 쓴 뒤 전투기와 파일럿만 골라요. 단원·난이도·전장은 보여 주기만 해요(설정 저장 후 12초 안에 반영).
3. 같은 반에서 별명이 같으면 같은 학생으로 기록되니, 별명이 겹치지 않게 안내해 주세요.

## Render 연결 방법
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올려요.
2. Render → New → Web Service → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start` / Instance Type: Free
4. Environment에 `TEACHER_PASSWORD`를 원하는 비밀번호로 넣어요.

## 꼭 알아 둘 점
- Render 무료 서버는 15분 동안 아무도 안 쓰면 잠들고, 잠들거나 다시 배포하면 **저장된 기록이 지워져요.**
  수업이 끝나면 교사 관제실에서 **엑셀(CSV) 받기**로 기록을 내려받아 두세요.
- 기록을 오래 보관하려면 Render 유료 Disk를 붙이고 환경 변수 `DATA_DIR`을 그 디스크 경로로 지정하면 돼요.
- 서버 첫 접속은 잠에서 깨느라 30초~1분 걸릴 수 있어요. 수업 시작 전에 한 번 열어 두세요.

## 문제 고치기
`public/index.html` 안의 `const UNITS = [` 부분에 단원별 단어(words)·문장(sents)·묻고 답하기(qa)가 있어요.
문장의 `[대괄호]` 부분이 빈칸 문제가 돼요.
